# Lumina legacy archive

Lumina's screen-saver and event-tap product was retired when Hikari became
the only shipped app. These sources, manifests, and screen-saver-only core
tests are kept for historical reference and are intentionally not included in
the Hikari Xcode target.

Hikari keeps `~/Library/Application Support/Lumina` as its canonical library
so existing Lumina data remains available. A former Hikari Native Local
library is merged once at first launch and retained as a recoverable archive.
