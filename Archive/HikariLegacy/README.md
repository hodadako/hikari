# Hikari legacy archive

Hikari's screen-saver and event-tap product was retired when Hikari became
the only shipped app. These sources, manifests, and screen-saver-only core
tests and the original PRD are kept for historical reference and are
intentionally not included in the Hikari Xcode target.

Hikari keeps `~/Library/Application Support/Hikari` as its canonical library
so existing pre-Hikari data remains available. A former Native Local
library is merged once at first launch and retained as a recoverable archive.
